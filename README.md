# Proyecto-2---Procesamiento-de-Imagenes

ACLARACION DE MENU:
El menú cuenta con 5 opciones.
Del 1 al 4 llama a una función y esta debería de ejecutarse y volver al menú. Ya que Google colab no permite un input luego de una imagen, decidi colocar un break despues de cada función para que no se rompa el programa.
Si se desea utilizar el menu en otro editor de codigo como Visual Studio Code, hay que sacar los breaks despues de cada funcion.
